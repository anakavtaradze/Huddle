# Rooftop cinema artwork

The built-in imagegen tool generated `rooftop-cinema.png` for Huddle's home screen. The project bundles the PNG locally for both web and Vega builds. The platform adapters supply the source in the format that each bundler expects.

The generator used this final prompt:

> The artist creates a premium cinematic illustration for a social movie-night app named Huddle. The scene shows a small group of silhouetted friends sharing an outdoor rooftop cinema at night, with a giant glowing orange moon, a distant midnight-blue city skyline, warm coral lights, and electric-lime highlights. The illustration uses sophisticated editorial 3D art, soft atmospheric grain, expressive lighting, and deep shadows. The composition places the people and projector on the right two thirds and gives the left third dark negative space. The image contains no text, logos, lettering, watermarks, or interface. The image uses a wide landscape composition.
